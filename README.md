# J-OSLER 進捗管理ツール（症例登録 ＆ 病歴要約）

内科専攻医研修（J-OSLER）の進捗を管理するための、単一ファイルのWebアプリです。

- **① 症例登録**：全70疾患群を13領域に分けて表示。登録チェック・件数・病名メモ・作成中／作成済みの状態・★要約候補を管理。修了要件（56群以上／120症例以上／各領域50%以上／外来1割／初期研修60まで）の達成度を可視化。
- **② 病歴要約（29篇）**：分野別の必要数に沿った29枠を、疾患群プルダウン・評価ステータス・外来/初期研修・分野内の重複検出つきで管理。

データは**閲覧者それぞれの端末のブラウザ内（localStorage）**にのみ保存されます。サーバーには一切送信されず、各自が自分の進捗を独立して管理できます。

## GitHub Pages での公開手順

1. GitHubで新しいリポジトリを作成（例：`josler-tracker`、Public）。
2. `index.html` をリポジトリ直下にアップロード（ドラッグ＆ドロップ → Commit）。`manifest.json` も同じ場所に一緒にアップロードしてください（ホーム画面の名前用）。
3. リポジトリの **Settings → Pages** を開く。
4. **Build and deployment → Source** を「Deploy from a branch」にし、Branch を `main` ／ フォルダを `/ (root)` に設定して **Save**。
5. 1〜2分待つと `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます。このURLを共有すれば誰でも利用できます。

## 注意

- 各領域の必要数・上限は「専門研修プログラム整備基準【内科領域】改定第2版」等に基づく一般的な内訳です。年度・プログラムで細目が異なる場合があるため、確定前に最新の手引き・統括責任者に確認してください。
- localStorage保存のため、ブラウザの履歴消去・シークレットモード・別端末では進捗は引き継がれません。
